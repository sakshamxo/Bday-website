# Birthday surprise website

Open `index.html` in a browser to run the site. It is designed as a full-screen story; only the rose bouquet scene scrolls.

## Adding your photos

1. Create an `assets` folder next to `index.html` and add your image files there.
2. In `script.js`, replace each `image:null` in the `memories` list with the image path, such as `image:'assets/us-1.jpg'`.
3. You can personalize the balloon notes, card captions, and final letter in the same file and in `index.html`.

## Adding background music

Add your chosen MP3 as `assets/birthday-music.mp3`. Music starts after the first tap, because browsers do not allow background audio to start automatically.
